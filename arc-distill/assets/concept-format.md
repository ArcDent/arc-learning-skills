# 考点清单格式

arc-distill 写入 `concepts.md` 的格式契约。audit_concepts.py 按此校验，arc-concept-quiz、arc-examiner、arc-dashboard 按此解析。

## 条目模板

id 加六字段（定义 / 要点 / 原文 / 出处 / 依赖 / 状态）。id 用 `D-三位数字` 编号，课题内唯一、永不复用、改名不改 id。

```markdown
### {id} {名称}（{类型}）

- 定义：{一句话说清这是什么}
- 要点：
  - {可检验要点 1，写成能判断对错的陈述句}
  - {可检验要点 2}
- 原文：{1~2 句逐字摘录，供脚本回验；材料讲不清时写（缺失）}
- 出处：{材料短名} <!-- p.N -->
- 依赖：{前置条目 id，如 D-003；多个逗号分隔；无则留空}
- 状态：☐
```

- 原文必填，是 audit 脚本回验的依据，锚点写概念在产物中实际所在页。
- 出处可多行，同一概念多份材料都讲过时逐条追加。
- 公式条目的名称用 LaTeX，如 `$F=C-P+2$`。
- 类型五选一：定义 / 事实 / 公式 / 流程 / 关系。
- 状态：arc-distill 只写 ☐，之后只由 arc-concept-quiz 改。

## 状态四值

本节是 arc 系列状态取值的唯一定义，其他 skill 一律引用这里。

| 写法 | 含义 |
|---|---|
| `☐` | 未测 |
| `待复验 @ YYYY-MM-DD` | 当场答对，日期为答对当天；日期早于今天才可复验 |
| `☑` | 已掌握，复验通过 |
| `⚠` | 有误解，判 miss 或复验没过 |

## 总清单头部模板

```markdown
# {课题名} 考点总清单

- 维护：arc-distill 增量合并，手动编辑会被保留
- 口径：定义 / 事实 / 公式 / 流程 / 关系
- 条目排序：按依赖顺序，无依赖的按类型分组

## 条目

{逐条排列}
```
