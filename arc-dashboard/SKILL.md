# arc-dashboard 进度仪表盘

从学习数据现算指标，填进 `assets/dashboard-template.html` 的注入槽，生成仓库根 `dashboard.html`：单文件，浏览器直开，可提交。数据源、注入 JSON 结构与字段口径只在 `assets/data-contract.md` 定义。

## 铁律

1. **只读不改**：数据源一律只读，唯一的写操作是生成 `dashboard.html`。
2. **只填 JSON**：生成时只替换注入槽，不手改产物的版式、模块、样式。界面要变只改模板文件，改完重跑注入验证。
3. **不编数**：算不出的指标（文件缺失、解析失败、字段缺失）给空值，由模板省略对应模块，并在汇报里说明缺哪个源。禁止估算、补默认值、凑整。
4. **每次现算**：不读旧的 `dashboard.html` 做增量。

## 流程

1. **盘点**：按契约的数据源表逐个确认存在与否。
2. **计算**：按契约算出注入 JSON 的每个字段，算不出的记入「本次省略」。
3. **注入**：校验 JSON 合法后替换注入槽，写仓库根 `dashboard.html`。
4. **自查**：产物里无占位符残留；页面无 JS 报错、未出现「数据注入失败」块；渲染出的数据模块与第 2 步有数据的字段一致。不过关就修到过关。
5. **汇报并停止**：列出产物路径、渲染与省略的模块及所缺数据源；全空时说明引导页已就位，提示先用 `/arc-materials`、`/arc-distill` 造数据。
