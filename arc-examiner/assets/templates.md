# 出题文件模板

题目文件学生可见，答案文件私有。两文件同名对应，答案文件头部元数据与题目文件相同，另加三节。公式用 LaTeX，`$...$` 包裹，与课程材料一致。

## 题目文件

```markdown
# {题名}

- 日期：YYYY-MM-DD
- 考点：{D-xxx 概念名}、{D-xxx 概念名}（清单外考点只写文字）
- 难度：基础 / 进阶 / 挑战
- 题型：选择 / 填空 / 简答 / 证明
- 认知层级：记忆 / 理解 / 应用 / 分析 / 评价 / 创造
- 来源：{材料出处，或「自编」}

## 题目

{题干。只有题干与求解要求，不得夹带提示。}
```

## 答案文件

```markdown
## 参考答案

{完整推导或解答}

## 分步要点

{按步骤列出的得分点，供 drill 批改时逐段核对}

## 常见错误

{学生最容易卡或做错的 1-3 处，供 drill 出变式与提示时参考}
```

出选择题时在「常见错误」后追加干扰项设计：

```markdown
## 干扰项设计

{每个错误选项对应「常见错误」里的哪一条误解，一行一条；没有对应误解的凑数选项不得出现}
```
