# 概念问答文件格式

问答文件落 `{课题夹}/concept-sessions/YYYY-MM-DD-概念问答.md`，同日已有同名文件加序号 `-2`、`-3`，目录不存在则创建。

## 问答文件模板

首行状态标记机器可读，供续场识别，不得省略。

```markdown
<!-- arc-concept: open -->

# 概念问答：{课题名}

- 日期：YYYY-MM-DD
- 清单：{课题夹}/concepts.md

> 随时可写：跳过（这题不考）、讲给我听（直接讲）、结束（做完这批就停）

## 第 1 批

{有当日待复验条目时写：当日记录，顺延至下场：{id 列表}}

### 1. {id} {概念名}（新题 / 复验 / ⚠ 重测）

**问题**：{题面}

**你的回答**：

{留空，学生填}

**结论**：{过 / 没过}

**订正**：{只在没过时写}

**订正回答**：

{留空，学生填}

**订正结论**：{过 / 没过}

### 2. {id} {概念名}（…）

{本批其余题同构；再来一批时追加「## 第 2 批」}

## 终场

- {id} {概念名}：{旧状态} → {新状态}（过 / 订正后过 / ⚠ / 跳过 / 复验 ☑）
- 同类小错：{点名一次；没有写「无」}
- 结果：过 N 个，⚠ N 个，跳过 N 个，复验 N 个
```

## 状态标记与登记

- 状态标记二选一：`<!-- arc-concept: open -->` 进行中，`<!-- arc-concept: done -->` 已完结。
- 作废：首行改 `done`，文件末尾写「- 结果：中止于第 N 批，本批未回写」；不登记。已批完各批的漏洞早已写进 `gaps.md`，不用补写。
- `.local/quiz-index.jsonl` 每场一行 JSON：`date`、`topic`、`results[]`、`file`。`results[]` 每概念一项：`id`、`name`、`old`、`new`，跳过的加 `skipped: true`。

## 问法库

一题只考 1 个核心点（认法见 SKILL.md「核心点与批改口径」），从下面抽 1 型设问，订正里的小变式换一型：

1. 举一个实例
2. 给一个反例
3. 换一组新条件会怎样
4. 与相邻概念对比
5. 划定边界，什么算什么不算

题面按概念现写。
