# 答题对局文件格式

两个文件的落点见 SKILL.md 文件约定。目录不存在则创建，同日同名的学生文件加序号 `-2`，计划文件随之同名。

## 学生文件模板

首行状态标记机器可读，供续场识别，不得省略。

```markdown
<!-- arc-drill: open -->

# 答题：{题目短名}

- 日期：YYYY-MM-DD
- 来源：{用户贴的文本 / 指定的文件路径 / arc-examiner：<题名>}

## 题目

{题目原文，逐字照录，不改写}

## 第 1 轮（摸底）

**问题**：{摸底问题}

**你的回答**：

{留空，学生填}

**提示**：（本轮未触发）

**tutor 结论**：

{摸底三分类结论}

## 第 2 轮（第 1 步 / 共 {m} 步）

**问题**：{当前这一步的问题}

**你的回答**：

{留空，学生填}

**提示**：（本轮未触发）

**tutor 结论**：

{批改时写入}

{后续轮次同构；终局轮标题写「第 N 轮（终局：写骨架）」}

## 解题骨架

{骨架定稿}

## 通关总结

{格式见下文}
```

## 轮内四节

每轮固定四节，顺序不变：问题、你的回答、提示、tutor 结论。提示未触发写「（本轮未触发）」。

## 计划文件格式

```markdown
# 计划：{题目短名}

- 学生文件：{课题}/drills/YYYY-MM-DD-题目短名.md

| 步 | 做什么 | 核对要点 | 状态 |
|---|---|---|---|
| 1 | {这一步的目标} | {关键式子或结论} | 进行中 |
| 2 | {…} | {…} | 未开始 |

{某一步拆细或讲解过时，在表下记一行：第 k 步在第几轮拆细或讲解，拆成了哪几问}
```

状态取「未开始 / 进行中 / 通过」。

## 状态标记

三选一：`open` 进行中 / `passed` 通关 / `surrendered` 认输。只记在首行标记里，正文不另写状态行。

## 摸底结论格式

第 1 轮「tutor 结论」写三行分类，没有的类别写「无」：

- `- 可用联想：…` 方向正确的思路
- `- 存疑联想：…` 方向拿不准的想法
- `- 空白：…` 没思路或只有模糊方向

## 通关总结格式

每项一行。漏洞不写在这里，只记进课题 `gaps.md`，见 SKILL.md「漏洞」。

- `- 联想验证：{联想} → 对/错 @ YYYY-MM-DD`
- `- 收尾结论：{一句话总评}`
